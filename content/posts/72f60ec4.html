前言

curl 是开发者、运维人员最常用的命令行网络工具，用于快速发起网络请求、调试接口和传输文件。使用最简示范：

curl [options] <URL>

常用命令示例

# 简单 GET
curl https://example.com

# 保存到文件
curl -O https://example.com/file.zip
curl -o output.html https://example.com

# POST JSON
curl -X POST -H "Content-Type: application/json" -d '{"key":"value"}' https://api.com

# POST 表单
curl -d "name=foo&age=18" https://api.com

# 带认证
curl -u user:pass https://api.com

# 跟随重定向 + 显示头
curl -i -L https://example.com

# 只看响应头
curl -I https://example.com

# 调试模式
curl -v https://example.com

# 上传文件
curl -T file.txt https://example.com/upload

# 表单上传文件
curl -F "file=@file.txt" https://example.com/upload

选项说明

短参数 长参数 说明
​-o ​--output 保存到指定文件
​-O ​--remote-name 按远程文件名保存
​-i ​--include 显示响应头
​-I ​--head 只显示响应头（HEAD 请求）
​-X ​--request 指定方法（POST/PUT/DELETE）
​-d ​--data POST 数据
​-H ​--header 添加请求头
​-u ​--user 用户认证（user:pass）
​-L ​--location 跟随重定向
​-v ​--verbose 详细调试信息
​-s ​--silent 静默模式（不显示进度）
​-k ​--insecure 忽略 SSL 证书验证
​-f ​--fail 失败时返回非0退出码
​-m ​--max-time 最大超时时间（秒）
