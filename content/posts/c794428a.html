• 安装（pip）

pip install mujoco -i https://mirrors.aliyun.com/pypi/simple/ # 使用阿里源安装 mujoco
pip install mujoco_viewer -i https://mirrors.aliyun.com/pypi/simple/ # 使用阿里源安装 mujoco_viewer
快捷键 功能描述
鼠标操作
左键拖动 绕视点旋转相机（Trackball 旋转）
右键拖动 平移相机
中键拖动 / 滚轮 缩放相机（推进/拉远）
双击左键 将相机对准选中物体或几何体
相机模式切换
F 切换自由相机（Free camera）
T 切换跟踪相机（Track selected object）
选择与扰动
左键单击 选中几何体（选中后高亮显示）
Ctrl + 左键拖动 对选中物体施加扰动力（Perturb selected object）
仿真控制
Space / P 暂停 / 继续仿真
Backspace 单步仿真（Step forward when paused）
→ (右箭头) 前进一步（当暂停时）
← (左箭头) 后退一步（仅在启用 undo 时有效）
Enter 重置仿真到初始状态（Reset simulation）
显示选项切换
H 显示/隐藏关节层级树（Hierarchy panel）
O 显示/隐藏选项面板（Options panel）
J 显示/隐藏关节信息面板（Joint panel）
A 显示/隐藏约束信息面板（Constraint panel）
~ (波浪键) 显示/隐藏所有 UI 面板（Toggle all panels）
0 - 9 切换不同可视化标签（Visualization labels）
[ 减慢仿真速度（Slow down）
] 加快仿真速度（Speed up）
Esc 退出仿真查看器
其他实用
R 重新加载模型文件（Reload model）
S 保存当前相机视角为默认（Save camera as default）
L 切换光源跟踪相机（Light tracks camera）
V 切换垂直同步（VSync on/off）
? 显示帮助信息（Show help overlay）

进入交互模式后，按 ? 可在窗口内查看完整快捷键帮助。
