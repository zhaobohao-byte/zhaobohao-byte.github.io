【Docker】

2026.01.06更新于 2026.01.08命令查询

镜像管理命令（Image）

docker pull nginx:latest         # 从 Docker Hub 下载指定镜像
docker images                    # 列出本地所有镜像
docker image ls                  # 同上，等价命令
docker rmi nginx:latest          # 删除指定镜像
docker build -t myapp:1.0 .      # 根据当前目录的 Dockerfile 构建镜像
docker tag myapp:1.0 myapp:latest # 为镜像打新标签
docker push myapp:latest         # 将本地镜像推送到远程仓库
docker save -o myapp.tar myapp:latest   # 将镜像保存为 tar 文件
docker load -i myapp.tar         # 从 tar 文件加载镜像

容器管理命令（Container）

docker run -d --name web -p 80:80 nginx   # 启动一个后台容器并映射端口
docker ps                        # 列出正在运行的容器
docker ps -a                     # 列出所有容器（包括已停止的）
docker stop web                  # 停止指定容器
docker start web                 # 启动已停止的容器
docker restart web               # 重启容器
docker rm web                    # 删除已停止的容器
docker rm -f web                 # 强制删除运行中的容器
docker exec -it web bash         # 进入运行中的容器执行交互式命令
docker logs web                  # 查看容器日志
docker logs -f web               # 实时跟踪容器日志
docker inspect web               # 查看容器详细信息
docker stats                     # 查看所有运行容器的资源使用情况

容器清理命令

docker container prune           # 删除所有已停止的容器
docker image prune               # 删除悬空镜像（未被任何容器使用的镜像）
docker image prune -a            # 删除所有未被容器使用的镜像
docker system prune              # 清理未使用的容器、网络、镜像和卷
docker system prune -a           # 更彻底的清理，包括未使用的镜像

卷（Volume）管理命令

docker volume create mydata      # 创建一个卷
docker volume ls                 # 列出所有卷
docker volume rm mydata          # 删除指定卷
docker volume prune              # 删除所有未使用的卷

网络（Network）管理命令

docker network ls                # 列出所有网络
docker network create mynet      # 创建自定义网络
docker network rm mynet          # 删除网络
docker network prune             # 删除所有未使用的网络

Compose（多容器编排）命令

docker compose up                # 根据 docker-compose.yml 启动服务
docker compose up -d             # 后台启动服务
docker compose down              # 停止并删除服务相关的容器、网络等
docker compose logs              # 查看服务日志
docker compose restart           # 重启服务
docker compose pull              # 拉取服务所需镜像

其他实用命令

docker version                   # 查看 Docker 客户端和服务端版本
docker info                      # 查看 Docker 系统信息
docker search nginx              # 在 Docker Hub 搜索镜像
docker login                     # 登录 Docker Hub 或私有仓库
docker logout                    # 退出登录
