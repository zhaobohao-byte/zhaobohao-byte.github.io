【.sh】

2025.12.30更新于 2026.01.09命令查询

文件的基本结构

行 内容 说明
第 1 行 ​#!/bin/bash 指定解释器（Shebang）
后续 Linux 命令 按顺序执行
注释 ​# 注释内容 不执行

位置参数说明

变量 含义
​$0 脚本名
​$1 第 1 个参数
​$2 第 2 个参数
​$@ 所有参数

核心语法

功能 语法
Shebang ​#!/bin/bash
执行脚本 ​./a.sh
变量 ​A=10
用变量 ​$A
参数 ​$1 $2 $@
打印 ​echo
sleep ​sleep 1
后台 ​cmd &
等待 ​wait
if ​if [ ]; then fi
for ​for ...; do done
exit ​exit
返回值 ​$?
source ​source xxx.sh
注释 ​#
  • 比较
if [ $A -gt 10 ]; then
  echo "A 大于 10"
fi
# 所有[ ]内部必须带空格
  • 命令替换
# 把命令执行结果当变量
TIME=$(date +%s)
echo "时间戳: $TIME"
  • 数组
freqs=(100 200 500)

for f in "${freqs[@]}"; do
  echo "频率: $f"
done

常用语法

功能 示例
判断文件 ​[ -f file ]
判断目录 ​[ -d dir ]
字符串比较 ​[ "$A" = "x" ]
数值比较 ​[ $A -gt 10 ]
while 循环 ​while true; do ... done
重定向 ​> >> 2>
管道 ​|
trap 信号 ​trap cleanup INT
读输入 ​read var
case ​case $x in esac
  • 比较
A=10
B=2

[ $A -gt $B ]   # 正确
[ "$A" = "$B" ] # 字符串比较
  • 快速判断
# &&：前一个成功才执行
# ||：前一个失败才执行
mkdir data && echo "创建成功"
rosrun motor_control node || exit 1
  • 重定向
# >：覆盖写文件
# >>：追加写文件
# 2>：错误输出
echo "hello" > log.txt
echo "world" >> log.txt
  • 管道
# 前一个命令的输出 → 后一个命令的输入
rostopic list | grep motor
  • 自动清理
# 脚本被 Ctrl+C 终止时，先执行清理代码
cleanup() {
  echo "停止电机"
  killall motor_node
}

trap cleanup INT
  • 多分支判断
# 多分支判断，常用来解析参数
case $1 in
  start)
    echo "启动"
    ;;
  stop)
    echo "停止"
    ;;
  *)
    echo "用法: $0 {start|stop}"
    ;;
esac
